# Initial Domain Taxonomy

**Version:** 0.1  
**Status:** Provisional

Categories may be added, split, merged, or renamed during D1–D3.

## Cross-cutting dimensions

Records may also carry dimensions such as:

- city / parish / municipality / intermunicipal / regional;
- resident / student / worker / business / visitor / public body / association;
- information / coordination / transaction / operational / physical / regulatory;
- accessibility;
- inclusion;
- sustainability;
- data availability.

Cross-cutting dimensions should not be duplicated as new domains unless discovery shows that they require independent treatment.
