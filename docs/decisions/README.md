# Decision Records

This directory is reserved for durable decisions that materially affect the programme and are likely to need historical context.

Do not create a decision record for every minor edit.

Suitable subjects include:

- change to programme scope;
- change to evidence governance;
- decision to build or not build shared data infrastructure;
- adoption of a major interoperability standard;
- product selection;
- material privacy/licensing policy;
- ownership/maintenance model;
- major architectural choices after Delivery begins.

A lightweight decision record should contain:

```text
ID
Date
Status
Context
Decision
Alternatives considered
Consequences
Evidence / references
```

Current D0 decisions are maintained in the baseline Discovery documents until a decision-record threshold is reached.
